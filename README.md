## Editorial progress

This tracker covers the current working edition of each book. Git and the versioned build artifacts preserve earlier release history. Update a status deliberately; a checkmark does not require a separate review log or issue.

- ⬜ not started or not assessed
- 🟡 underway or present but not approved
- ✅ complete
- — optional or not applicable

Print and paid-store readiness are outside this tracker. The five human editorial passes normally happen in this order: **structural → substantive → verification → copyedit → final proof**.

### Process

| Milestone | Complete when |
| --- | --- |
| Import | The intended source material is present and safe refresh and locking behavior is established. |
| Rights | Licenses, permissions, sources, and text and image attribution have been audited. |
| Shape | Scope, chapter order, cuts, duplicates, gaps, and stale web-only material have been resolved. |
| Introduction | An original editor introduction explains the source, audience, selection, edition choices, and how to contribute back. |
| Foreword | An optional contributed foreword has been granted, licensed, and recorded in [SOURCES.md](SOURCES.md). |
| Conclusion | An original ending synthesizes the book, acknowledges limitations, suggests practical next steps, and points to the living source. |
| Structural edit | Organization, balance, repetition, transitions, and missing material have been reviewed. |
| Substantive edit | Clarity, usefulness, tone, coherence, and internal consistency have been reviewed chapter by chapter. |
| Verification edit | Facts, links, safety advice, privacy, source notes, licenses, and attribution have been checked. |
| Copyedit | Grammar, spelling, terminology, headings, captions, and house style are consistent. |
| Final proof | The complete rendered edition has been proofread after copyediting. |
| Visual audit | Design is settled and every image is relevant, licensed, attributed, accessible, and unique within the book. |
| Format QA | EPUB, PDF, and HTML build successfully and have been checked visually and functionally. |
| Release | Reviewed, versioned EPUB, PDF, and HTML files are live on the free catalog. |

### After a source refresh

- Reopen shape, structural, or substantive editing only when changed material affects those milestones.
- Always reopen verification, final proof, format QA, and release for the new edition.
- Preserve the status of unaffected milestones.

See [SOURCES.md](SOURCES.md) for adjacent sites, permission notes, and titles wanted later (philosophy / free software / abundance / AI / wikis). See [EDITORIAL.md](EDITORIAL.md) for how to edit chapters so wiki updates do not wipe them. See [PUBLISH.md](PUBLISH.md) for print and stores (KDP, Lulu, Ingram, D2D, itch.io, Internet Archive). NC-SA stays off paid stores.

Each book has its own cover, type, and colors from the related website (`make covers`, `scripts/themes.py`). See each book’s `DESIGN.md` for logos and hex values.

Wiki XML/ZIM dumps belong in `dumps/` (gitignored). Resized JPEGs in `books/*/images/` are also gitignored; keep `images.json`. Restore with `make images` (disk, then the `images` GitHub Release, then the live site, then wiki). Refresh the archive with `make images-release`.

Server copies (gitignored under `dumps/`):

- Hitchwiki/Nomadwiki/Trustroots/Trashwiki XML+ZIM from [dumps.hitchwiki.org](https://dumps.hitchwiki.org/)
- Optional private SQL / Drupal node dumps via `scripts/pull_server_dumps.sh` (SSH hosts in gitignored `local/hosts.env`; page content only, no user tables)

```sh
cp local/hosts.env.example local/hosts.env   # then set the SSH hosts
scripts/pull_server_dumps.sh
python3 scripts/compile_drupal_sql.py
```

Builds are versioned `0.1-yyyymmdd-hhmm` (UTC).

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
make fetch   # dumps into dumps/, then compile chapters (keeps locks / editorial notes)
make images  # disk, GitHub release `images`, live site, then wiki URLs
make images-release  # pack JPEGs and upload/update the `images` release
make         # open the catalog at http://127.0.0.1:8000/
make all     # EPUB, PDF (if a PDF engine exists), HTML
```

Do not mix chapters across books. CC-BY-SA and CC-BY-NC-SA are not one work.
