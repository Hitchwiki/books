# Repository instructions

Before working on any book, read the shared [editorial guidelines](EDITORIAL.md). They apply to every book in this repository.

Some books also have their own `books/<slug>/EDITORIAL.md`. When one exists, read it as well; it supplements the shared guidelines for that book. If the two conflict, follow the book-specific guidelines for that book.

Do not generate or edit book text with AI unless the user specifically requests that work.

## Images

Do not use the same image twice in a book. The only intended exception is a cover image that also appears inside the book, such as on its title page or a chapter opener.

When placing, keeping, or fetching images:

- If a file is already used in that book's `src/`, skip it. The same photo under a different filename or path still counts as a duplicate.
- If a wiki dump repeats a photo across chapters, keep one placement and drop the rest.
- Do not fill a chapter with a photo already used elsewhere in the same title.
