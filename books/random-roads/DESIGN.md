# Design

Visual identity for this book, taken from Random Roads (a hitchhiking zine on Drupal, sharing the Moneyless theme).

## Sites

| Site | Role |
| --- | --- |
| [randomroads.org](https://randomroads.org/) | Source magazine |

## Logo

Wide **Random Roads** wordmark (heavy rounded serif, white on transparent). Site header file:

- Live: `https://randomroads.org/sites/randomroads.org/files/randomroads_hitchhiking_magazine_1_0_1.png`
- Local: `assets/logos/random-roads.png`

Favicon is olive `#90a800` plus brick red — a second mark, not the header.

## Colors

The site runs the shared **moneyless** Drupal theme. Distinctive hex from aggregated CSS:

| Token | Hex | Use |
| --- | --- | --- |
| Teal | `#0ca6bb` | Links, rules, cover field |
| Cyan | `#42d0e3` | Secondary accent |
| Gold | `#f0c020` / `#fea` | Highlights |
| Paper | `#ffffea` | Page |
| Ink | `#261c14` | Text |
| Green flash | `#47c965` | Occasional UI |

Cover sits the white wordmark on teal so the transparent PNG reads.

## Type

Magazine type as on [randomroads.org](https://randomroads.org/): **Georgia** for stories and titles (the Drupal body face), **Open Sans** for chrome (kicker, banner, TOC — the Google Font the moneyless theme loads). The masthead is still the PNG wordmark, not a webfont.

## Applied

Seth Doyle’s bright 2017 country-road hitchhiker photograph under teal masthead bars, cream paper, white zine wordmark, Georgia titles. Drop cap in Georgia. Walker Evans’s 1936 hitchhikers photograph is retained as an interior historical image.
