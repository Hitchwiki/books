# Still Growing

Regardless of the silence we've had for nearly a year now, Random Roads is still growing! We released a couple of more stories that had been submitted before and new submissions are very welcome.
The printed magazine is still pending. We will still be working on this, one day for sure you can have a printed copy in your hands! The plans for now are first to migrate the website to the lastest Drupal release and to redesign the website.
Part of this is to make it easier to work on the website from the back-end, with a clearer distinction of material that has been submitted and material that has been 'accepted' and edited.
Get on the [e-maillist](http://lists.freeactive.net/listinfo.cgi/randomroads-freeactive.net) if you want to be involved!
