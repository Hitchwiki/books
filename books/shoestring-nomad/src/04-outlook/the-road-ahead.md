# Nomadic futures

"Digital nomad" became a product: rent, wifi, the same café in a new country. That life is real for some people. It is not what Nomadwiki was for. This book is the other stack — camping, tramp skills, nomadbases, asking, sharing, staying off the meter when you can.

Visas get tighter in some places. Phones make you findable. Climate makes long-haul flying look worse and local weather look stranger. None of that deletes the old methods. A field, a tap, a ride, a spare room still work. They work better when someone wrote down how.

Nomadbases come and go. Casa Robino did. The pattern remains: a house that treats guests as the point, not as inventory. If you can open one, even for a season, do it. If you cannot, be a good guest in someone else's.

Use the live tools. [Nomadwiki](https://nomadwiki.org/) is the current book. This file is a snapshot. Hitchwiki, Trashwiki, and the hospitality networks belong beside it, not inside a second copy here.

The future of this is more people who can leave without a script, and more pages that tell the truth about a place. If a chapter here is wrong, fix it on nomadwiki.org. If a camp died or a base opened, write it. If you lived cheaply somewhere for a month, leave the method.

This book ends. You do not have to. Someone else's first week on the road is next month. Leave them a page.
