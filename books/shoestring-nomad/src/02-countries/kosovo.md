# Kosovo

**Kosovo** is a new independent republic in southeastern Europe, which has been under United Nations administration since 1999.

## Border crossing {#border_crossing}

Crossing to [Serbia](Serbia "Serbia"){.wikilink} used to be difficult if you entered Kosovo from [Albania](Albania "Albania"){.wikilink} or [Macedonia](Macedonia "Macedonia"){.wikilink}. Nowadays (2014) it should be easier and you should be able to enter with ID card and hence not have \"wrong stamps\" in your passport.
