# List of ecovillages

The following is a **list of ecovillages**. An [ecovillage](ecovillage "ecovillage"){.wikilink} is an [Intentional Communities](Intentional_Communities "Intentional Communities"){.wikilink} which strives to be socially, economically, and ecologically [sustainable](sustainability "sustainable"){.wikilink}.

A more complete listing of ecovillages can be found on the external website [ic.org](http://www.ic.org)
