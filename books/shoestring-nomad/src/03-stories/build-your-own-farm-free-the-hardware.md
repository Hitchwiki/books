# Build Your Own Farm - Free the Hardware!

It is pretty unusual for me to [link to a TED-video talk](http://video.ted.com/talk/podcast/2011U/None/MarcinJakubowski_2011U-480p.mp4), but this one is so close to the heart and the casa-philosophy that I can't let it go. In this video Marcin from [openfarmtech.org](http://openfarmtech.org) explains in four minutes why [open hardware](http://p2pfoundation.net/Open_Hardware) is so important, and amazingly groundbraking. Thanks Tau for letting me know, Anu for always being [so close](http://casarobino.org/2009/03/diy-farm) to the source and TED for picking this up.
Open Source Ecology is a network of farmers, engineers, and supporters that has been imagining and creating the Global Village Construction Set, an open source, low-cost, high performance technological platform. These DIY-fabricated industrial machines can be used to build a sustainable civilization with modern comforts. The GVCS lowers the barriers to entry into farming, building, and manufacturing. It is a life-size lego-like set of modular tools that can create entire economies.
And yeah, I wanna build [that bread-oven](http://openfarmtech.org.nyud.net/wiki/Product_Ecologies) :)
