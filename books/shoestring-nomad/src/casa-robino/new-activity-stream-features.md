# new activity stream features

Since it was winter again, I started reading more and then I found out we actually didn't have an [activity stream](/stream) item for books that you've read.

Now we do. I added [Good Reads](http://www.goodreads.com) to the list, as well as other sources of your (online) activity such as [Identica](http://identi.ca) (microblogging), [Foursquare](http://foursquare.com/), [Ravelry](http://www.ravelry.com/) (for knitting!) and [blip.tv](http://blip.tv), in addition to the ones we already had such as twitter, flickr, any rss-feed, delicious, etc.
