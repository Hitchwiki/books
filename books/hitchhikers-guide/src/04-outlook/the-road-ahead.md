# The road ahead

Hitchhiking is supposed to be finished, and has been supposed to be finished for decades. In some rich countries it got rarer. In a lot of the world it never left: a normal way to move when the bus is empty or expensive. Petrol still costs money. Seats still sit empty. People still like company.

What changed is the phone. You can summon a paid ride. You can be mapped. You can read last year's spot that is now a no-stopping zone. Use the live tools. [Hitchwiki](https://hitchwiki.org/) and [maps.hitchwiki.org](https://maps.hitchwiki.org/) are the current book. This file is a snapshot.

The other change is the reason. Sharing a car is still one of the cheapest climate tricks that does not require a new gadget. An empty seat is waste, same as food in a bin.

Hitchgathering, the clubs, and the meetings in the practice pages are how this culture finds itself. They are not a membership card. Show up if you want faces with the usernames.

The future of this is not an app that replaces the roadside. It is more people who know how to stand, more pages that are not stale, more drivers who remember they have room. If a chapter here is wrong, fix it on hitchwiki.org. If a ramp died, say so on the map. If you got a ride, write the waiting time.

This book ends. The road does not. Someone else's first time is tomorrow. Leave them a page.
