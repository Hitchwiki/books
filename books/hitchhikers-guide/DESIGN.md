# Design

Visual identity for this book, taken from Hitchwiki — not an invented “travel handbook” palette.

## Sites

| Site | Role |
| --- | --- |
| [hitchwiki.org](https://hitchwiki.org/) | Source wiki |
| [hitchhiking.org](https://hitchhiking.org/) | Current Hitchwiki-family landing (same org; live CSS when the wiki is behind a bot wall) |

## Logo

Yellow square: **HITCHWIKI** in brown, thumbs-up hitchhiker below.

- Live wiki: `https://hitchwiki.org/en/images/logo.png`
- Local: `assets/logos/hitchhikers-guide.png`
- Graphics repo (CC BY-SA 4.0, Mikael Korpela): [Hitchwiki/hitchwiki-graphics](https://github.com/Hitchwiki/hitchwiki-graphics)

## Type

Hitchhiking.org uses **Nunito**. This book keeps **Source Serif 4** for long reading and a heavy sans (Oswald) for the cover kicker, matching the all-caps wiki wordmark.

## Applied

Cover and catalog use the yellow header field with the hitchhiker mark. Body text sits on cream, links in ochre.
