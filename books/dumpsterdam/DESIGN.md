# Design

Visual identity for this book, taken from dumpsterdam.nl.

## Sites

| Site | Role |
| --- | --- |
| [dumpsterdam.nl](https://dumpsterdam.nl/) | Source site (Robino) |

## Logo

Header `<img>` is **Trasher-grey** — the same dumpster/Trasher silhouette Trashwiki uses, 150×150 on olive-beige.

- Live: `https://dumpsterdam.nl/sites/dumpsterdam.nl/files/Trasher-grey.jpg`
- Local: `assets/logos/dumpsterdam.png` (same mark at wiki resolution)

Site name is typeset next to it: “Dumpsterdam” / “Dumpster Diving - Voedselactivisme - Workshops - Catering - Lezingen”.

## Colors

From dumpsterdam.nl aggregated Drupal CSS (not an invented orange):

| Token | Hex | Use |
| --- | --- | --- |
| Brick | `#9a2016` | Primary, cover, headings |
| Olive | `#759236` | Secondary bar, links |
| Ink | `#111111` | Text |
| Paper | `#fff6ea` | Page |
| Sky | `#7bb9e0` | Occasional UI |
| Gold | `#f0c020` | Highlights |
| Drupal link fallback | `#0072b9` | Unused here |

## Type

**Oswald** for the Dutch title slab, **Source Sans 3** for body.

## Applied

Brick-red field, olive side bar, Trasher mark. Distinct from Trashwiki’s green-on-olive even though the dumpster drawing is shared.
