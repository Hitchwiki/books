# The waste stream ahead

The goal is not more dumpsters. The goal is less waste. If shops stop throwing good food, diving gets harder, and that is a win. Until then, the alley is still full.

Some places lock more than they used to. Some places run apps that give away what would have been binned. Some cities still put whole pallets of yoghurt on the pavement. Trashwiki exists because that mix will not sit still, and because a pin from 2014 is a rumor.

Use the live tools. [Trashwiki](https://trashwiki.org/) and [dumpstermap.org](https://dumpstermap.org/) are the current book. This file is a snapshot. Meetings, Food Not Bombs, freeshops, and the other community pages in the practice section are how people find each other. They are not a brand.

The future of this practice is not a secret list of bins. It is more people who notice abundance, take only what they will use, and say so in public so the next person is not guessing. If a chapter here is wrong, fix it on trashwiki.org. If a spot died or a lock appeared, say so on the map. If you cooked something good from what you found, write the method.

This book ends. The waste stream does not, not yet. Someone else's first look in a bin is tonight. Leave them a page.
